# Argus · 企业级多 Agent 深度研究平台

> 求职作品项目 · 开发中（M0 底座与语料）。
> 企业尽调 / 竞争情报研究自动化：输入研究目标 → 多 Agent 并行调查 → 产出每句可溯源的尽调报告。

- 技术栈：Python 3.14 · FastAPI · PostgreSQL 16（单一事实源）· MCP · 自研任务图运行时
- 姊妹项目：Aegis — 企业级智能客服 Agent 平台（互链占位，M6 回填）。
  一句话组合叙事：Aegis 管住**一个 Agent 的纵深**，Argus 管住**一群 Agent 的横向协作**。
